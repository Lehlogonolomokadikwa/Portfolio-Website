# Portfolio Website Design Document

## Project Overview

This portfolio website is designed to present my technical skills, projects and professional journey as an aspiring IT professional

The objective is to create a modern, responsive and accessible portfolio tht reflects professionalism, technical competence and attention to detail.

---

# Design Philosophy

The design follows a **Modern Enterprise Technology** aesthetic.

The website should communicate:

- Professionalism
- Simplicity
- Trust
- Technical Conpetence
- Consistency

The overall experience should resemble modern technology companies rather than a student assgnment.

---

# Target Audience

- Recruiters
- Hiring Managers
- Graduate Programme Coordinators
- Technology Professionals
- Potential Employers

## Navigation Layout

The navigation uses CSS Flexbox because it provides a simple and responsive way to position the logo and navigation links horizontally while keeping them vertically centered.

Key properties:

- display: flex
- justify-content: space-between
- align-items: center
- gap: 2rem
